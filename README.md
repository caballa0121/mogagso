## 주요 시스템

### 턴제 카드 전투
마디(턴) 단위로 공격·수비를 주고받는 카드 전투입니다.
회피, 공격 반사, 반격, 원호방어, 합공, 광역 공격, 독/출혈 등의 효과를 카드에 붙일 수 있습니다.

`Assets/Code/Combat/`

### 노드맵
칸을 하나씩 밟아 목적지까지 나아가는 진행 맵입니다.
칸마다 전투 / 함정 / 빈칸이 숨어 있고, 전투에서 지면 시작 지점부터 다시 시작합니다.
파티 체력은 맵 전체에 걸쳐 유지됩니다.

`Assets/Code/NodeMap/`

### 퍼즐
흩어진 조각을 끌어다 한 장의 그림으로 맞춥니다.
조각 이미지를 폴더에 넣고 에디터 도구를 돌리면 정답 좌표까지 자동으로 계산됩니다.

`Assets/Code/Puzzle/`

### 연출 / 대화
스텝 단위로 캐릭터 이동·표정·배경·사운드·컷씬을 순서대로 재생하는 연출 시스템과,
초상화와 컷씬 일러스트가 함께 나오는 대화 시스템입니다.

`Assets/Code/cutscene/`, `Assets/DialogueManager.cs`

### 탐험 / 보스전
맵을 돌아다니며 NPC와 대화하고, 피아노 연주와 보스전을 진행합니다.

`Assets/BossSequence.cs`, `Assets/Piano*.cs`

## 에디터 도구

개발 편의를 위해 만든 메뉴들입니다. Unity 상단 `Tools` 에 있습니다.

| 메뉴 | 하는 일 |
|---|---|
| 노드맵 → 노드맵 씬 만들기 | 노드맵 씬을 배선까지 끝난 채로 생성 |
| 퍼즐 → 조각 이미지 재단 | 조각 PNG를 잘라 정답 좌표 자동 계산 |
| 씬 → Build Settings 순서 정리 | 진행 순서대로 빌드 목록 재정렬 |
| UI → 빌드 목록의 모든 씬 고치기 | Canvas 해상도 대응 일괄 설정 |
| 사운드 → 모든 캐릭터 프리팹에 버튼 클릭음 넣기 | 프리팹 일괄 설정 |
